# Ethics And Use

This project involves Adja language text and speech produced with community and
speaker participation. Public release should preserve informed consent, speaker
privacy, and non-exploitative use.

Default policy for human-translated text and speech assets is gated
non-commercial access unless a specific artifact has been reviewed and approved
for a more permissive release.

Before publishing any new artifact:

- confirm consent scope for text, audio, speaker metadata, and derived models;
- remove private notes, raw local paths, and accidental identifiers;
- document intended use, limitations, and prohibited misuse;
- keep existing experiment dependency repos unchanged.
